# 离线人球轨迹

同一比赛的 `Tracker` 按曝光 UTC 从早到晚处理对齐的观测窗口。输入是当前有效机位的外参报告和逐机位的原始图像观测，输出是 v2 的 `players`、`ball` 以及供身份、姿态、动作复核使用的原帧证据。

- 对可见足点逆畸变，从相机中心发出射线，与球场地面 Y=0 相交。脚部缺测、射线平行地面、交点位于机后或场景范围外时跳过这次足点定位。
- 各视角按机位 ID 顺序处理。用一对一最小费用匹配关联投影足点，同一组内任意两点相距至多 1.25 米。具有不同球队候选的两个足点分开处理。融合位置按观测置信度加权。
- 跨帧使用最近实测的有界速度匹配轨迹。原帧序号和球衣号均独立于轨迹 ID。每帧最多 32 名，优先保留多视角实测，其次按观测置信度排序。轨迹超出预测时限后给出 `lost`，1 秒内可重新关联。长期离场后分配新 ID。
- 足球需要两个或更多视角，交会锐角至少 1°，重投影 RMS 至多 3 像素。三至四路可用时优先取通过检验的最大多数视角子集。相近残差支持多个相距超过 0.5 米的解时保留缺测。单视角像点保存为二维证据。人球均从最后一次实测起最多外推 0.3 秒。
- 场景中的 `views` 给出实测所用机位。局部证据以轨迹 ID 索引，保留 `cameraId`、`captureUtcUs`、`segment`、`pts`、可选的 `mediaEpoch` 及原始二维 `player` 对象。保留键 `_ball` 记录有效机位检出的二维 `ball`，包括未进入最终三角化的机位。
- 标定切换时，`reset_geometry(affected)` 从上次实测中移除已变更机位的贡献，使用余下足点恢复球员位置，并清除旧速度。仅有已变更机位支持的球员重新出现时分配新 ID。足球至少需要两个仍有效的机位可以重新三角化才能继续预测。全量复标可调用 `reset_geometry()`。

以上距离、速度和时限是离线算法参数。球员交叉时的身份连续性依赖可区分的运动和球队观测，快速折返或完全重叠时仍可能误关联。可从仓库根目录运行几何回归。

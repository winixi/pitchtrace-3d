# 离线比赛的身份、骨骼与动作候选

比赛重建按曝光时刻更新每条场地轨迹。网络快照使用 v2 的 `teamId`、`number`、`rosterId`、`yawRad`、`bones`、`events`。Edge 归档可按同一帧键取回测量、参与机位、原始二维标注、媒体周期及原帧 PTS。[场景契约](../schemas/v2/scene-frame.schema.json)

## 球队、背号与换人

同一曝光窗口内各路对同一字段的一致读数计一票。两秒内最多保留最近七次有读数的窗口。获得至少三票且占当期窗口七成以上时确认。持续缺读数时沿用同一轨迹的已确认值，遇到矛盾读数时暂停该字段的确认。按球队、号码和曝光时刻匹配唯一有效的名单项。多个轨迹同时声称同一名单时暂停该绑定，可通过人工修正指定其中一条。

同号换人可用半开 UTC 微秒区间表示。下面的配置片段在指定曝光时刻起允许将主队 7 号与替补名单关联。`fromUtcUs` 默认从 0 生效，省略 `untilUtcUs` 表示持续有效。

```json
{
  "roster": [
    {"rosterId":"starter-7","teamId":"home","number":7,"untilUtcUs":"1795494600000000"},
    {"rosterId":"sub-7","teamId":"home","number":7,"fromUtcUs":"1795494600000000"}
  ],
  "identityCorrections": [
    {"trackId":"p-000018","fromUtcUs":"1795494600000000","teamId":"home","number":7,"rosterId":"sub-7"}
  ]
}
```

人工修正针对配置所属的这次重建，按轨迹和曝光区间替换身份字段。同轨迹区间不可重叠。显式给出 `rosterId` 时必须与该人在该区间登记的球队和号码一致。修正后复算使用新的 `streamEpoch`，可与原结果按时刻对照。

## 关节与绑定骨骼

对匹配到同一人的每个关节，使用当前有效机位的原始像点、内外参及畸变进行三角化。最少两个视角、至少一对视线交角达到 1°，重投影均方根误差不超过 4 像素，结果距该人的足点不超过 3 米。每关节保存来源视角、重建状态、可得的原始坐标和残差。局部旋转使用时间常数 45 毫秒的因果平滑坐标，关节丢失、标定切换和超过 250 毫秒的帧间隔会截断平滑。动作识别使用实测关节和球心。

模型局部 +X 指向解剖左侧、+Z 向上，转换与 `clips.glb` 的 `grf_zup_to_yup` 节点一致。双髋、双肩确定身体朝向、骨盆和胸廓坐标架，肩肘腕、髋膝踝确定各段弯曲。在父骨骼坐标中计算局部四元数，使用最小转动估计骨段方向。单段轴向扭转仍无独立测量。需要耳鼻来估计头部转向，需要趾尖来估计脚掌朝向。观测不足的节点省略。归档测量可按 `trackId` 查看 `joints` 内的原始和平滑位置。姿态的米制精度需有独立三维参考才能计量。

## 动作与原帧复核

候选只基于连续实测球心及人体观测。两次曝光相隔超过 250 毫秒、球缺测或标定切换会清除待判定时窗。实测踝点在球心 0.65 米内，且比第二近的球员至少近 0.15 米时，才将该球员计作可能持球者。规则、阈值和指标用于离线复算。

| 候选 | 触发所需的证据 |
| --- | --- |
| 踢球、射门 | 三个连续帧组中，前一帧球靠近踝点，脚相对身体沿出球方向摆动至少 1.2 米/秒，离脚后球速至少 3 米/秒、增速至少 2 米/秒。配置 `pitchLengthM` 和 `goalWidthM` 后，若出球点距前方端线不超过 32 米且水平运动方向在三秒内穿过球门宽度，细分为射门候选。 |
| 传球 | 有离脚证据，球至少移动 2 米，三秒内由另一条已知同队轨迹连续两帧接近球。保留起脚、出球和接球的机位引用。 |
| 带球 | 同一人连续近球至少 0.6 秒，人和球在至多两秒的窗口中各移动至少 1.6 米。一次持续持球只生成一次带球候选。 |
| 过人 | 满足带球条件，遇到已知对方球员，运动方向上的相对位置从落后超过 0.35 米变到领先超过 0.35 米，途中两人相距小于 1.5 米。 |
| 铲球 | 对方前一帧近球，挑战者整体移动超过 1.2 米/秒。重建的同侧髋膝踝显示髋低于 0.65 米、脚踝低于 0.35 米且伸腿接近球。此项描述动作形态，接触先后与判罚由人工复核。 |

每个事件记录 `status: "candidate"`、起止 UTC、轨迹 ID、来源帧引用和触发指标。`confidence` 是所用人球观测的最低质量分。输入缺少质量分时为 `null`。动作分类的精确率、召回率和 F1 仍需标注样本测量。

从仓库根目录运行 `python3 -B edge/Tests/Integration/test_match_analysis.py`，可复验跨队同号、人工修正、替补生效时刻、独立视图的关节缺测、GLB 局部旋转、连续摆腿与五类候选，以及预测球中断时的行为。

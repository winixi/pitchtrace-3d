# 场迹 · PitchTrace 3D 详细需求说明

**适用范围**　业余足球场实拍试点，覆盖场边设备、Mac mini 边缘计算、三维数据分发和浏览器回看。本文用于确定现场试点能否交付。实施方法见[技术实现方案](02-technical-design.md)，排期与验收责任见[落地开发计划](03-development-plan.md)。

## 1. 产品目标与交付基线

第一阶段 MVP 在球场四个独立支架 A–D 上各设一台单摄像头，连续拍摄同一场比赛。M6 Mac mini 将四个同步视角的观测还原为同一球场坐标系下的球员、足球和骨骼运动。教练能在网页里找回一次传球，切到接球队员背后看跑位；遇到滑铲争议时，能逐帧查看双方脚部、球和同步实拍，记录人工判断。

| 性质 | 内容 |
| --- | --- |
| 用户已明确 | 第一阶段四路单摄、Mac mini 边缘节点、端到端延迟上限 5 分钟、多角度观看、基本写实人物模型可选、球衣号码、性别信息、骨骼和比赛动作。 |
| 仓库已有 | Three.js 直播前端内置 60 秒比赛，支持六种机位、骨骼显示、v1/v2 场景快照和独立 HLS 观看。本地试播网关接收并转发 v1 快照。[前端](../live/web/) · [试播接口](../live/server/) |
| 待开发 | 相机采集与同步、现场标定、从视频识别人员和球、跨视角追踪、三维姿态、号码识别、真实比赛的延时直播和实拍复核。模拟比赛用于离线展示和回归。 |
| 待试点确认 | 场地实际尺寸、比赛人数、照明、架设位置、相机接口、Mac mini 配置、可取得的报名资料。建议先用小场或半场训练做联调，再按目标场地和实际人数验收。 |

**MVP 范围。** 首次联调建议选小场或半场，先打通球员跑位、地面传球和同步原片回看。场勘时冻结验收区域、人数和光照条件。高球、骨骼与拼抢按同一范围采样，分别报告可测和缺测时段。后续按实测盲区评估新增机位或局部双目。

第一阶段的 5 分钟（300 秒）从**现场曝光到浏览器首次绘制对应画面**计时，包含排队、推理、传输和播放缓冲。结果就绪即可发布。下文的精度、负载和可用率数字是首轮试点的**建议验收值**，需在场勘后冻结。它们没有经过目标设备实测。

### 两个子项目分别怎样验收

- **边缘计算。** 给定带时间码的录像或现场四路相机，能独立录制，输出带质量状态的场景帧、各机位视频片段和逐帧时间索引。关闭直播服务后，现场采集继续运行；恢复连接后可追到缺口和补交结果。设备、几何与识别主要对应 R01–R07。
- **直播。** 给定符合契约的场景快照和实拍片段，能独立运行网关和浏览器，完成观看、切换实拍视角、同步回看和审核。使用同一组固定样例即可验收 R07–R12 的展示、复核、访问和归档功能。
- **联合验收。** 同一次传球从现场曝光到网页首次绘制须满足 R09 的延迟门槛；从事件跳回原片须满足 R10 的时间定位门槛。分别通过单端测试后，仍需在目标场地验证这两项。

## 2. 使用者与比赛流程

| 角色 | 操作 | 成功表现 |
| --- | --- | --- |
| 场务人员 | 安装设备、选场地配置、检查同步和标定、建赛、开赛及结束归档 | 赛前可看到四个预览、每路延迟和缺流原因；移动相机后收到重标定提示。 |
| 教练或分析员 | 导入双方名单、校正号码和身份、寻找事件、切机位、导出片段索引 | 输入“蓝队 7 号”可找到该球员；换人和换边可追溯；能从事件跳到原始片段。 |
| 网页观众 | 打开比赛链接、跟球、跟球员、自由环绕、暂停回看、返回延时直播 | 暂停后换角度保持同一比赛时刻；恢复直播时看到当前可用的新帧和数据状态。 |
| 比赛复核员 | 查看接触前后原片与骨骼，标记“确认／排除／证据不足” | 候选事件保留来源、审核人和版本；原片不足时可保留未决结果。 |

标准流程为赛前配置与采样检查、开赛、持续采集与重建、浏览与事件复核、终场归档。若比赛中一台相机短暂断线，系统应继续发布其他相机支持的结果，画面可识别出受影响对象，设备恢复后自动重新对时。

## 3. 功能需求与可观察的验收行为

**P0** 为首场实拍试点的必交能力，**P1** 在首场闭环后交付，纳入完整项目验收。每个编号在另外两份文档中沿用。

| 编号 | 优先级 | 需求与验收行为 |
| --- | --- | --- |
| R01 | P0 | 建赛、配置四个单摄机位和场地尺寸，记录每个镜头的序号、安装位、曝光时钟和标定版本。回放时可还原使用的配置。 |
| R02 | P0 | 接入四路画面，支持实时与录像重放两种输入。记录曝光时间戳、帧号、帧率、丢帧和同步偏差。场务可查看指定机位的原始视频流。拔掉一路后出现具体通道告警，恢复后可持续采集。 |
| R03 | P0 | 标定镜头内参、各机位姿态以及场地绝对坐标。系统给出独立检查点误差和覆盖图；发现支架移动时可隔离该视角并更新版本。 |
| R04 | P0 | 检测、连续追踪球员和足球，输出稳定人员 ID、球员落地点、球心三维位置、观测来源和质量。覆盖长传、起高球、出界、人员交叉、球被遮挡。丢失、短时预测和重新观测要能区分。 |
| R05 | P0 | 给球员关联队伍及球衣号，号码不可辨时显示“未知”，保留人工修订。性别信息首版按报名名单中的本人填报或授权字段关联；支持未提供、人工纠错和隐藏展示。是否另需图像分类由项目方确认。 |
| R06 | P0 | 从实拍重建肩、肘、髋、膝、踝等关键点，并映射到有头颈连接的基础写实模型。提供至少两种可选外形；模型、队服和号码分别配置。近景能看到踢球时支撑腿与摆动腿；关节证据不足时显示低可信状态。 |
| R07 | P0 | 定位传球、踢球或射门、带球、过人和铲球候选，记录时间窗、相关球员及可用机位。支持复核潜在犯规，区分“动作候选”“接触线索”和“人工判定”；可用原片核对触球与接触顺序。 |
| R08 | P0 | 自动导播、自由环绕、边线、球门、战术俯视和球员近景共享同一时间轴；可选人、慢放、暂停、逐帧、恢复延时直播。实拍模式显示时延、缺测及过期状态，保留单独的演示入口。 |
| R09 | P0 | Mac mini 在目标人数、四路输入和约定照明下持续处理。监控端显示曝光到显示的延迟分布、发布率和超期率。拥塞时按技术方案降级，避免队列无限增长。 |
| R10 | P0 | 分段保存源视频、标定、比赛名单版本、场景帧和事件索引。用比赛时间和相机编号能取回同一动作的原片；进程恢复后保留已落盘数据与断点。 |
| R11 | P0 | 场务有设备健康视图、开始／停止和故障恢复操作；采集写入、观看、身份修订、原片访问使用相应权限。赛前配置录像留存期，支持到期清理与人工删除；公开演示只发布获准使用的数据。 |
| R12 | P1 | 比赛结束后按事件、人员和时间检索，导出轨迹及事件索引；支持从归档重新计算，保留算法、标定及人工审核版本，允许对两次结果进行比较。 |

## 4. 数据规则与异常处理

- **身份。** 比赛内的轨迹 ID、名单 ID、球衣号分别存储。两队同号按球队区分。替补入场、共享号码、读号冲突和遮挡后的身份合并都须保留时间范围和证据。更正号码后，历史轨迹继续使用原轨迹 ID。
- **空间。** 以中圈地面为原点，X 沿长边、Z 沿短边、Y 向上，单位米。半场交换进攻方向只更新比赛元数据。足球使用球心高度，球员用足底与地面交点定位。
- **时序。** 原始采集时间、比赛时间、入库时间和显示时间可相互追溯。暂停回看使用比赛时间，延迟统计使用校准后的物理时钟。出现时间跳变时分段并显示缺口。
- **缺测。** 没认出号码、球飞出可视区、只有一个视角看见高球、双方脚部被挡，均为有效的系统状态。未知属性可留空；预测带状态和时限；原片留存以便复查。
- **显示与使用。** 球员性别和模型选择是独立字段。观看公开比赛不需要展示名单隐私信息。复核界面保留比赛原片与估计骨骼的对应关系，裁判或复核员负责解释接触动作。

## 5. 试点验收口径

使用同一版带现场尺度的校验集，分别报告近端、远端、日间或灯光、无遮挡或遮挡的样本量。验收集按比赛划分，调参样本另存。在中圈、禁区与边线等试点区域逐区记录至少两个同步机位同时看清同一球或关键关节的时隙比例，按地滚球、高球和拼抢分别报告。遗漏的帧和无法识别的目标计入覆盖率，防止仅在易识别片段上计算精度。

| 检查项 | 建议门槛与方法 |
| --- | --- |
| 同步与几何（R02、R03） | 在四路视野拍摄共同闪光或带时间码移动标记，曝光偏差 P95 ≤5 ms；保留最大值。预留场地点独立核验，地面位置误差 P95 ≤0.30 m；另在已知高度检查高点并报告误差。 |
| 轨迹（R04） | 对已标注、处于覆盖区的球员，位置输出覆盖率 ≥95%，地面位置误差 P95 ≤0.75 m。可见球覆盖率 ≥85%，有独立三维参考的球心误差 P95 ≤1.0 m，地滚球与高球分开。每 10 球员分钟身份切换 ≤1 次。 |
| 读号与身份（R05） | 双人确认可读的轨迹段中，自动确认号的正确率 ≥95%、自动确认覆盖率 ≥70%；另报全部轨迹段覆盖率和误绑数。抽查已提供的名单字段、未提供、被隐藏及人工更正四种情况。 |
| 姿态与动作（R06、R07） | 对可见且有独立三维参考的主要关节，球场坐标下平均误差 ≤0.20 m；另报可见关节输出覆盖率，建议 ≥80%。五类动作分别报告精确率、召回率、样本数，宏平均 F1 建议 ≥0.75。接触先后无法分辨的样本保留“证据不足”。 |
| 延迟与连续性（R08、R09） | 目标配置连续运行 90 分钟。建议至少 99% 的预期输出时隙在对应曝光后 300 秒内首次绘制，缺帧或超期均计入失败时隙。另报实际显示帧的延迟 P50、P95 和最大值。超期画面带过期提示。建议场景发布 10 Hz，分别报告正常和降级时段。 |
| 回看与恢复（R07、R08、R10） | 抽 20 个事件，从事件跳到各路原片，同步定位偏差 ≤1 个采集帧；暂停后换机位，比对同一场景帧序号。注入断流、断网和进程重启，检验缺口记录、重连和已保存片段。 |
| 权限与归档（R11、R12） | 分角色验证原片读取、修改名单、发布帧与删除留存；未授权操作被拒绝。用一段归档重放并导出，按轨迹 ID、时间窗、版本与场景记录逐项对照。 |

验收报告需要附设备配置、场地图、标定与模型版本、原始统计、典型失败片段和复核人。报告注明实测人数和场地尺寸；扩展到更大球场或更多球员时须重新测量覆盖和时延。

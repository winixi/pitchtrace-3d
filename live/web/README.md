# 场迹 · 直播观赛前端

[打开离线观赛页](dist/index.html)。在本机用浏览器打开该文件，即可观看内置的 60 秒比赛。HTML 中包含 Three.js、球员、球场和动作数据，默认启动时无需连接直播服务。首次打开时界面和页眉品牌默认显示英文，在右上角切换简体中文后显示「场迹」。语言选择保存在本地。

| 入口         | 行为                                                                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **内置演示** | 播放两段模拟攻防，可拖动时间轴、慢放、循环和切换六个机位。返回演示时保留先前的演示进度。                                                                     |
| **人物展示** | 独立的 48 秒展示，包含正面转头、侧面抬臂、背面颈肩、跑动、射门、滑铲和门将扑救。可选择跟随球员、切换近景和体型、暂停或慢放检查变形。                         |
| **连接直播** | 输入比赛的 `ws://` 或 `wss://` 地址。收到有效场景帧后进入三维直播，支持切机位、跟随球员、骨骼显示、定格及返回最新画面。断线后保留状态并重连。                |
| **本机试播** | 连接示例服务的 `/demo`，用模拟网络流演练连接、定格和重连。使用下方命令启动服务。                                                                             |
| **实拍视频** | 进入直播模式后，展开「实拍视频」，输入 HLS 播放列表地址。视频有独立播放控件，回到内置演示会断开视频。媒体服务器需允许浏览器访问对应片段，跨域时需配置 CORS。 |

## 录制三维画面

播放内置演示、人物展示或三维直播时，点击播放器下方的「开始录制」。页面会显示已录制时长，切换机位、调速或暂停会反映在片段中。点击「停止录制」结束，再点击「下载视频」保存。片段为无声的三维画面，浏览器会根据编码支持生成 MP4 或 WebM 文件；离线观赛页也可录制。

## 直接运行

从仓库根目录启动示例网关，再打开 <http://127.0.0.1:8766/>。这个入口可在同一页体验内置比赛、WebSocket 试播以及外部推送到示例网关的 v1 数据。

```sh
node live/server/server.cjs
```

## 开发与部署

前端使用 Vite 和 Three.js。开发环境使用 Node.js 20.19+ 或 22.12+ 的受支持版本。

```sh
cd live/web
npm ci
npm run dev
```

`npm test` 检查内置比赛及数据协议；`npm run build` 生成 `dist/index.html`。可将此单文件部署在静态站点，也可直接用支持 WebGL 2 的浏览器打开。本机试播网关直接提供同一份构建产物。

## 人物模型与展示

- **头颈连接**：头部与颈根共用连续表面，缩短外露颈长，中颈收窄、颈根外扩。蒙皮权重沿实际前低后高的领口过渡；立体领圈有圆润厚度与细小织纹，跟随胸骨，避免抬臂或转头拉扯领口。
- **手部**：保留原网格的五指结构，调整手掌与手指比例、指端微屈和轻微肤色层次。三种体型均在手腕匹配前臂的位置、权重与法线，减少材质分界处的硬接缝；门将仍使用手套外观。手指为固定的自然微屈形状，当前 13 关节协议不含独立手指输入。
- **体型与外观**：精瘦、标准、壮硕三种体型在绑定空间调整躯干和四肢横截面，共用骨长与足球动作。10 名演示球员固定分配四种肤色、短发／寸头／光头和不同发色，门将使用专用队服与手套外观。「人物体型」可临时统一全场体型以便比较，选择「按球员配置」恢复阵容差异。
- **展示入口**：点击「人物展示」查看四名代表球员；自动导播按段切换正面、侧面、背面与动作近景。选择「球员近景」后，可在「近景范围」切换上半身、头颈与衣领、左手与手腕、右手与手腕，镜头随相应部位运动。展示与内置比赛分别保存播放位置；两者均支持现有的暂停、慢放、循环和六个机位。
- **边界**：这些外观是前端演示配置，依据轨迹 ID 稳定选择，与性别、号码和队伍独立；未扩展 v1/v2 数据契约。48 秒人物展示不影响网关 `/demo` 的 60 秒比赛。体型由现有素材在运行时生成，继续内嵌在离线单文件中。

## 连接比赛

- **v1** 使用示例网关的 `/live`。上游向 `POST /frame` 提交快照。详细字段和可运行的 curl 示例见[网关说明](../server/README.md)。
- **v2 场景快照** 使用 `matchId`、`streamEpoch`、`seq` 和 `matchTimeMs`。网页接受 [v2 示例](../../docs/02-technical-design.md#edge-live-contract)中的球员、球、骨骼和缺测状态。可以手动输入流地址；在同源部署中，链接 `/?match=trial-01` 会自动订阅 `/v2/matches/trial-01/live`。示例网关提供 v1；v2 订阅需要搭配对应的数据源。
- **切换与异常**　等待、无数据、断线和重新连接均显示状态。直播中可定格当前帧绕场观察，点击「返回直播」跳到最近帧。v2 空场、丢球和未知球衣号保留对应状态；同一场比赛、同一数据流周期内忽略重复和乱序的序号。
- **实拍对照**　HLS 支持浏览器原生播放或 hls.js。按曝光时刻定位原片的网关接口和逐帧同步回看仍在开发计划中。HTTPS 页面连接数据源时使用 WSS，并使用 HTTPS 视频源。

## 源码

`src/app.js` 管理演示、人物展示、直播与控制台，`src/match.js` 生成内置比赛，`src/showcase.js` 生成人物展示片段，`src/appearance.js` 管理体型与稳定外观，`src/anatomy.js` 负责领口、颈根、手部整形与接缝法线，`src/receiver.js` 接收和插值，`src/live-frame.js` 将场景快照转为渲染输入。`src/pitch.js`、`src/rig.js` 负责球场、机位和人物，`src/media.js` 管理实拍播放器，`src/i18n.js` 提供简体中文与英文界面文案，静态元素经 `data-i18n` 属性、动态元素经 `t()` 翻译，切换语言时按当前状态重算。模型和依赖的许可见[许可目录](licenses/)。
